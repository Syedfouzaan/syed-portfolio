# Syed Fouzan — Sci-Fi HUD Portfolio

A highly immersive, interactive sci-fi HUD portfolio built with Next.js, Framer Motion, and Three.js WebGL graphics. 

## Features
- Interactive 3D Warp Starfield
- Dynamic Neural Lattice Physics
- Segmented HUD Meters & Telemetry Readouts
- Fully Responsive Cyberpunk UI
- Next.js App Router (Server & Client architecture)

## Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the live interface.
